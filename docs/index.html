How this calendar series was set

The file repeats every other Wednesday at 4:00 p.m. Pacific, from September 23, 2026 through December 2, 2026. September 23 is the first Wednesday on the fall roadmap, so the repeat stays on that weekday rhythm: September 23, October 7, October 21, November 4, November 18, and December 2.

October 7 lands on that rhythm. It is not a labeled company session. December 9 is the roadmap finish, not an extra event in the file. The timezone is Pacific Time, so the clock stays at 4:00 p.m. across the daylight-saving change. The event lasts one hour only so a calendar has an end time — the flyer states 4:00 p.m., not a length.
